Hosted Web App at IPB discontinued

As of April 2026, we have taken the GoldenMutagenesisWeb Application previously hosted at the Leibniz Institute of Plant Biochemistry offline. You can still use the GitHub repository or the docker container to host your own instance. Please contact us if you are interested to contribute or maintain the app.
